# mzmzkgu.github.io

개인 사이드 프로젝트들을 한 곳에 모아놓은 "프로젝트 데스크톱" 허브 페이지.

## 구성
- `index.html` — 레트로 데스크톱 OS 컨셉의 랜딩 페이지. 아이콘 타일로 다른 프로젝트들(공모주 관리 `/ipotracker`, 사진 리사이즈 `/imgresize`, 배경 투명화 `/bgremove`, 무한매수 관리 `/infinityBuy` 등)로 연결
- `ads.txt`

## 소개
"네트워크·보안 엔지니어의 사이드 프로젝트 아카이브. 필요할 때 쓰려고 만든 작은 웹 도구들을 모아둠."
