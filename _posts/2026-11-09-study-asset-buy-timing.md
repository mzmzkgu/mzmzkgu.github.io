## 3줄 요약

1. 매월 정해진 액수씩 사모음
2. 달러, 금은 VIX 낮을 때
3. 미국주식은 VIX 높을 때

</div>

### [공통사항]

- 매월 <span class="red">정해진 액수</span>(비율)만큼 계속 사모음
- <span class="red">호들갑 떠는 뉴스</span> 나올 때 매수하면 대체로 이득
- 원화는 자산 관점으로 손해 <span class="red">(달러, 자산으로 보유)</span>
- 단기적으로는 수익률, 장기적으로는 <span class="red">보유수량</span> 중요
- 모든 자산은 <span class="red">최소 원화 수익률(3%)</span> 이상 나와야 함

<hr>

### [달러]

- <span class="red">VIX 낮을 때 + Greed</span> 구간에서
- 평화가 완연할 때, 대체로 평이한 시기 (전쟁 X)
- 달러는 외화RP로 월 단위로 묶음

### [미국주식]

- <span class="red">VIX 높을 때 + 공포(Fear ~ Extream Fear)</span>일 때
- 20이평선 아래 또는 급락할 때
- <span class="red">개별종목 당일 -5% 이상</span> 크게 빠질 때
- <span class="red">나스닥 당일 -3% 이상</span> 빠질 때 (마삼룰)

### [국내주식]

- <span class="red">당일 인덱스 3% 이상 급락</span>할 때 인덱스 ETF 매수
- 단, 빠른 시일 반등할 때 매도(국장은 장투 믿지말기)

### [코인]

- USDT : <span class="red">저환율(1300) / 김치프리미엄(3% 부근)</span>
- 원화 역 환전은 고환율 또는 김프 높을 때
- 알트코인 : BTC 5~20이평 급락 때 상승세 알트코인

### [금/은]

- <span class="red">VIX 낮을 때 + Greed</span> 구간 평화의 시기에 매수

### [원화]

- 중장기성 현금 : CD금리 ETF(3.5% 이상)로 묶음
- 단기성 현금 : CMA발행어음형(3.5% 부근)으로 묶음

### [채권]

- 미 국채 <span class="red">10년물 4.6% 이상</span>부터 분할 매수
- 가치 상승하면 팔고, 하락하면 이자 받으며 기다리기

<hr>

### [투자금 집행순서]

- 연금펀드 : 월 50만원
- IRP계좌 : 월 25만원
- 해외계좌 : 배당 + 남은 투자금 환전 달러의 50%
- 해외RP : 남은 투자금 환전 달러의 50%
- ISA계좌 : (별도) 3년 이상 자금 모을 때 (자녀, 적금)
