[무한매수 관리앱](https://mzmzkgu.github.io/infinityBuy/)은 로그인이 없고, 입력한 기록이 **내 폰이나 PC의 브라우저에만 저장**됩니다. 서버에 올라가지 않아서 안심이지만, 반대로 **브라우저 데이터를 지우거나 폰을 바꾸면 기록이 사라질 수 있다**는 뜻이기도 합니다. 특히 **폰 저장공간을 정리하다가 브라우저의 사이트 데이터가 같이 지워져서** 기록이 사라지는 일이 생각보다 흔합니다. 그래서 앱에는 기록을 파일 하나로 저장하고 다시 불러오는 **백업/복원** 기능이 있습니다. 이 글에서는 그 방법을 순서대로 정리했습니다. 앱 전체 사용법은 [무한매수법 관리앱 사용방법]({{ site.baseurl }}{% post_url 2026-10-23-infinite-buying-app-guide %})에서 볼 수 있습니다.

> 한 줄 요약: 폰 정리나 기기 변경 전에 **옵션(톱니바퀴) → JSON 백업의 [백업]** 으로 파일을 저장해 두고, 기록이 사라졌을 때는 **JSON 복원의 [복원]** 에서 그 파일을 고르면 됩니다.

## 특히 폰 정리할 때 조심하세요

무한매수 관리앱의 기록은 브라우저가 **"사이트 데이터"** 로 보관합니다. 그래서 폰 저장공간이 모자라 이것저것 정리하다가 **사이트 데이터가 같이 지워지면 기록도 함께 사라집니다.** 이렇게 지워지면 앱에서는 되돌릴 방법이 없습니다.

폰을 정리하다가 기록이 날아갈 수 있는 경우는 이렇습니다.

| 폰 정리 방법 | 기록이 사라질 수 있나요? |
|---|---|
| 브라우저의 **인터넷 사용 기록 삭제**에서 **"쿠키 및 사이트 데이터"** 까지 체크하고 삭제 | 사라집니다 |
| 폰 설정 → 앱 → 브라우저 → 저장공간 → **데이터 삭제**(캐시 삭제와 다릅니다) | 사라집니다 |
| 브라우저 앱을 **삭제했다가 다시 설치** | 사라집니다 |
| 폰 **초기화**, 새 폰으로 교체 | 사라집니다 |
| 제조사의 **저장공간 정리 기능이나 청소 앱** | 브라우저의 사이트 데이터까지 정리하는 경우가 있어 사라질 수 있습니다 |
| 브라우저의 **"캐시된 이미지 및 파일"** 만 삭제 | 보통 기록은 남지만, 같은 화면에 "사이트 데이터" 항목이 같이 있어서 실수하기 쉽습니다 |

그 밖에도 이런 경우가 있다고 알려져 있습니다.

- **폰 저장공간이 거의 가득 찼을 때**, 브라우저가 오래 쓰지 않은 사이트의 저장 데이터를 스스로 정리하기도 합니다.
- **아이폰 사파리**는 개인정보 보호 기능 때문에, 일정 기간(약 7일) 방문하지 않은 사이트의 저장 데이터를 지울 수 있습니다.

> 그래서 **폰을 정리하거나 용량을 확보하기 전에는 먼저 [백업]부터** 누르세요. 파일을 받아 두기만 하면 1분도 걸리지 않습니다. 이때 **백업 파일을 폰의 다운로드 폴더에만 두지 마세요.** 폰 정리를 하다가 다운로드 폴더를 비우면 백업 파일도 같이 사라집니다. 메일이나 클라우드에 한 부 더 올려 두는 것까지가 백업입니다.

## 이럴 때 백업이 필요합니다

- **폰 저장공간을 정리하거나 용량을 확보할 때**: 사이트 데이터가 함께 지워질 수 있습니다.
- **폰을 바꾸거나 초기화할 때**: 새 폰의 브라우저에는 기록이 없습니다.
- **브라우저의 사이트 데이터를 지울 때**: 앱 기록도 함께 지워집니다.
- **다른 브라우저나 PC에서 같은 기록을 보고 싶을 때**: 브라우저끼리는 기록이 공유되지 않습니다.
- **앱에서 전체 초기화를 하기 전**: 되돌릴 수 없습니다.
- **사이클이 하나 끝날 때마다**: 정기적으로 저장해 두면 안전합니다.

## 무엇이 저장되나요?

백업 파일 하나에 앱의 데이터가 통째로 들어갑니다.

| 저장되는 것 | 설명 |
|---|---|
| 계좌 | 계좌 이름, 종목, 별표(메인 계좌) 표시 |
| 매매기록 | 모든 계좌의 회차별 매수·매도 기록과 한줄메모 |
| 옵션 설정 | 다크 모드, 원화 표시, 회차당 최대 수량, 목표수익률 |

기록이 많아져도 파일은 작습니다. 제 경우 계좌 2개, 기록 52건 기준으로 약 28KB였습니다.

## 백업하는 방법

1. 앱 오른쪽 위의 **톱니바퀴 버튼**을 눌러 **옵션** 창을 엽니다.
2. 아래쪽 **JSON 백업**에서 **[백업]** 버튼을 누릅니다. (사진의 빨간 네모)
3. 앱에 **"백업 파일 생성됨"** 이라는 알림이 뜨고, 브라우저가 파일을 내려받습니다. 사진 위쪽처럼 **"다운로드 1개 완료"** 알림이 보이면 성공입니다.

![무한매수 관리앱 옵션 화면: 백업 버튼은 빨간 네모, 복원 버튼은 노란 네모로 표시](/assets/images/infinite-buying-backup/backup-button.jpg){: .phone}

*옵션 화면. 빨간 네모가 [백업], 노란 네모가 [복원]입니다. 위쪽에는 백업 후 브라우저에 뜬 "다운로드 1개 완료" 알림이 보입니다. (이미지를 누르면 크게 볼 수 있어요)*

내려받은 파일 이름은 **`infinity_buy_날짜.json`** 입니다. 예를 들어 10월 25일에 백업했다면 `infinity_buy_2026-10-25.json` 이 됩니다. 폰에서는 대부분 **다운로드 폴더**에 저장되지만, 브라우저 설정에 따라 다를 수 있으니 알림의 **[열기]** 로 위치를 확인해 두세요.

> 파일 이름의 날짜는 세계 표준시(UTC) 기준이라, 한국 시간으로 새벽 0시~9시 사이에 백업하면 **하루 전 날짜**가 붙을 수 있습니다. 파일 내용에는 영향이 없습니다.

### 백업 파일은 이렇게 보관하세요

- 폰에만 두지 말고 **나에게 메일 보내기**, **클라우드(구글 드라이브, 원드라이브 등)**, **메신저의 나에게 보내기** 중 하나에 한 부 더 올려 둡니다. 폰을 잃어버리거나 초기화하거나, **폰 정리하면서 다운로드 폴더를 비우면** 폰 안의 파일도 같이 사라지기 때문입니다.
- 파일에는 **내 투자 기록**이 들어 있습니다. 다른 사람에게 공유하지 마세요.
- 파일을 열어서 **직접 수정하지 마세요.** 형식이 깨지면 복원이 되지 않을 수 있습니다.

## 복원하는 방법

새 폰이나 다른 브라우저에서 앱을 열고, 백업 파일을 불러오는 순서입니다.

1. 새 기기의 브라우저에서 [무한매수 관리앱](https://mzmzkgu.github.io/infinityBuy/)을 엽니다.
2. 오른쪽 위 **톱니바퀴 버튼**을 눌러 **옵션** 창을 엽니다.
3. **JSON 복원**에서 **[복원]** 버튼을 누릅니다. (위 사진의 노란 네모)
4. 파일 선택 창이 열리면 백업해 둔 **`infinity_buy_날짜.json`** 파일을 고르고 **[완료]** 를 누릅니다.
5. **"현재 데이터를 덮어쓸거야. 진행할까?"** 라는 확인 창이 뜨면 **확인**을 누릅니다.
6. **"복원 완료 ✨"** 알림과 함께 옵션 창이 닫히고, 계좌와 기록이 화면에 나타납니다.

![복원할 때 뜨는 파일 선택 창: infinity_buy_2026-10-25.json 파일](/assets/images/infinite-buying-backup/restore-picker.jpg){: .phone}

*[복원]을 누르면 열리는 파일 선택 창(삼성 폰 기준). 백업 파일을 고른 뒤 아래의 [완료]를 누릅니다. 창의 모양은 폰 기종에 따라 다릅니다.*

백업 파일이 폰의 **최근 파일**에 안 보이면 **내장 저장공간 → Download(다운로드)** 폴더에서 찾아보세요. 메일이나 클라우드에 올려 둔 파일은 먼저 새 기기로 내려받아야 선택 창에 나타납니다.

### 복원할 때 주의할 점

- **복원은 덮어쓰기입니다.** 지금 앱에 있는 기록이 사라지고 백업 파일의 내용으로 바뀝니다. 두 기록이 합쳐지지 않습니다.
- 그래서 새 기기에서 이미 기록을 입력했다면, 복원하기 전에 **지금 상태를 먼저 한 번 백업**해 두세요. 덮어쓴 뒤에는 되돌릴 수 없습니다.
- **"잘못된 파일이야"** 라는 알림이 뜨면 앱에서 만든 JSON 백업 파일이 아니거나 파일이 손상된 것입니다. 파일 이름이 `infinity_buy_...json` 인지 확인하고, 다른 날짜의 백업 파일로도 시도해 보세요.

## 전체 초기화를 누르면?

옵션 맨 아래의 **[초기화]** 는 모든 계좌와 기록을 지우는 버튼입니다. 누르면 **"모든 계좌와 기록이 초기화됩니다. 백업하시겠습니까?"** 라는 확인 창이 뜹니다.

| 선택 | 결과 |
|---|---|
| 확인 | 백업 파일을 먼저 내려받고, 그다음 초기화합니다 |
| 취소 | 아무 일도 일어나지 않고 중단됩니다 |

실수로 눌러도 **확인을 누르면 백업 파일이 자동으로 만들어지니** 그 파일로 되살릴 수 있습니다. 다만 초기화를 정말 하려는 게 아니라면 **취소**를 누르세요.

## 자주 묻는 질문

**자동으로 백업되나요?** 아니요. 백업은 **직접 [백업]을 눌러야** 만들어집니다. 앱이 서버를 쓰지 않아서 자동 동기화도 없습니다. 그래서 사이클이 끝날 때마다, 또는 한 달에 한 번처럼 **나만의 주기**를 정해 두는 것을 권합니다.

**폰에서 만든 백업을 PC에서도 복원할 수 있나요?** 백업은 같은 앱의 JSON 형식이라서 기기가 달라도 같은 앱이라면 복원할 수 있습니다. PC 브라우저에서 앱을 열고 같은 순서로 [복원]을 누르면 됩니다.

**백업 파일은 몇 개나 모아 둘까요?** 파일이 작으니 날짜별로 여러 개 두어도 괜찮습니다. 가장 최근 파일 하나와, 사이클이 끝났을 때 만든 파일 몇 개 정도를 남기면 충분합니다.

**복원했더니 옵션(다크 모드 등)도 바뀌나요?** 네. 옵션 설정도 백업 파일에 들어 있어서 복원하면 그때의 설정으로 돌아갑니다.
