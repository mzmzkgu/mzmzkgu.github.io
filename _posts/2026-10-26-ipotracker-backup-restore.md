[공모주 관리 도구](https://mzmzkgu.github.io/ipotracker/)는 로그인이 없고, 입력한 거래 기록이 **내 폰이나 PC의 브라우저에만 저장**됩니다. 서버에 올라가지 않아서 안심이지만, 반대로 **브라우저 데이터를 지우거나 폰을 바꾸면 기록이 사라질 수 있다**는 뜻이기도 합니다. 특히 **폰 저장공간을 정리하다가 브라우저의 사이트 데이터가 같이 지워져서** 기록이 사라지는 일이 생각보다 흔합니다. 그래서 도구에는 기록을 파일로 저장하는 **데이터 추출**과, 그 파일로 되살리는 **백업 복구** 기능이 있습니다. 이 글에서는 두 기능의 사용 순서를 정리했습니다. 도구 사용법은 [공모주 수익 관리 방법]({{ site.baseurl }}{% post_url 2026-10-23-ipo-profit-tracking %})에서 볼 수 있습니다.

> 한 줄 요약: 폰 정리나 기기 변경 전에 **⚙️ 설정 → 데이터 추출**로 **JSON 파일**을 저장해 두고, 기록이 사라졌을 때는 **⚙️ 설정 → 백업 복구**에서 그 파일을 고르면 됩니다.

## 특히 폰 정리할 때 조심하세요

공모주 관리 도구의 기록은 브라우저가 **"사이트 데이터"** 로 보관합니다. 그래서 폰 저장공간이 모자라 이것저것 정리하다가 **사이트 데이터가 같이 지워지면 기록도 함께 사라집니다.** 이렇게 지워지면 도구에서는 되돌릴 방법이 없습니다. 청약, 환불, 상장, 매도 기록을 몇 달씩 쌓아 온 사람일수록 한 번에 잃는 것이 큽니다.

폰을 정리하다가 기록이 날아갈 수 있는 경우는 이렇습니다.

| 폰 정리 방법 | 기록이 사라질 수 있나요? |
|---|---|
| 브라우저의 **인터넷 사용 기록 삭제**에서 **"쿠키 및 사이트 데이터"** 까지 체크하고 삭제 | 사라집니다 |
| 폰 설정 → 앱 → 브라우저 → 저장공간 → **데이터 삭제**(캐시 삭제와 다릅니다) | 사라집니다 |
| 브라우저 앱을 **삭제했다가 다시 설치** | 사라집니다 |
| 폰 **초기화**, 새 폰으로 교체 | 사라집니다 |
| 제조사의 **저장공간 정리 기능이나 청소 앱** | 브라우저의 사이트 데이터까지 정리하는 경우가 있어 사라질 수 있습니다 |
| 브라우저의 **"캐시된 이미지 및 파일"** 만 삭제 | 보통 기록은 남지만, 같은 화면에 "사이트 데이터" 항목이 같이 있어서 실수하기 쉽습니다 |

그 밖에도 이런 경우가 있다고 알려져 있습니다.

- **폰 저장공간이 거의 가득 찼을 때**, 브라우저가 오래 쓰지 않은 사이트의 저장 데이터를 스스로 정리하기도 합니다.
- **아이폰 사파리**는 개인정보 보호 기능 때문에, 일정 기간(약 7일) 방문하지 않은 사이트의 저장 데이터를 지울 수 있습니다.

> 그래서 **폰을 정리하거나 용량을 확보하기 전에는 먼저 데이터 추출(백업)부터** 하세요. 파일을 받아 두기만 하면 1분도 걸리지 않습니다. 이때 **백업 파일을 폰의 다운로드 폴더에만 두지 마세요.** 폰 정리를 하다가 다운로드 폴더를 비우면 백업 파일도 같이 사라집니다. 메일이나 클라우드에 한 부 더 올려 두는 것까지가 백업입니다.

## 이럴 때 백업이 필요합니다

- **폰 저장공간을 정리하거나 용량을 확보할 때**: 사이트 데이터가 함께 지워질 수 있습니다.
- **폰을 바꾸거나 초기화할 때**: 새 폰의 브라우저에는 기록이 없습니다.
- **브라우저의 사이트 데이터를 지울 때**: 도구의 기록도 함께 지워집니다.
- **다른 브라우저나 PC에서 같은 기록을 보고 싶을 때**: 브라우저끼리는 기록이 공유되지 않습니다.
- **청약 시즌이 끝날 때마다**: 한 달에 한 번처럼 정기적으로 저장해 두면 안전합니다.

## 무엇이 저장되나요?

백업 파일에는 **모든 거래 기록**이 들어갑니다. 종목, 증권사, 공모가, 배정 수량, 매도가, 수수료, 제세금, 반납원금, 대출이자, 진행 상태, 비고까지 입력한 내용 전부입니다. 다크 모드 같은 **화면 설정은 파일에 들어가지 않습니다.**

기록이 많아져도 파일은 작습니다. 제 경우 거래 33건 기준으로 JSON 파일이 약 10.85KB, CSV 파일이 약 5.16KB였습니다.

## CSV와 JSON, 무엇을 고를까요?

데이터를 추출하면 두 가지 형식 중에서 고르게 됩니다.

| | CSV (엑셀) | JSON (완벽 백업) |
|---|---|---|
| 도구의 설명 | 표 형식 · 엑셀에서 쉽게 확인 | 원본 데이터 그대로 · 손실 없음 |
| 파일 이름 | `공모주_수익_날짜.csv` | `공모주_백업_날짜.json` |
| 이런 때 | 엑셀로 열어서 수익을 따로 정리하고 싶을 때 | **기록을 되살리려고 백업할 때** |
| 들어 있는 것 | 입력값과 함께 투자금, 수익, 수익률 같은 계산된 열도 포함 | 입력한 원본 값 |

CSV로도 복구는 되지만, 도구가 **"원본 그대로 · 손실 없음"** 이라고 안내하는 것은 JSON입니다. 그래서 **백업용으로는 JSON**, 엑셀로 보고 싶을 때만 CSV를 쓰는 것을 권합니다. 마음이 놓이지 않으면 **둘 다** 받아 두어도 됩니다.

## 백업(데이터 추출)하는 방법

1. 도구 오른쪽 위의 **⚙️ 톱니바퀴 버튼**을 눌러 **설정** 창을 엽니다.
2. **데이터 추출**(CSV 또는 JSON으로 내보내기)을 누릅니다. (사진의 빨간 네모)
3. 형식을 고르는 창이 뜨면 **JSON (완벽 백업)** 을 누릅니다. 엑셀용이 필요하면 **CSV (엑셀)** 도 함께 받습니다.
4. 브라우저가 파일을 내려받고, 사진처럼 **"다운로드 1개 완료"** 알림이 보이면 성공입니다.

![공모주 관리 도구 설정 창: 데이터 추출은 빨간 네모, 백업 복구는 노란 네모로 표시](/assets/images/ipotracker-backup/settings.jpg){: .phone}

*설정 창. 빨간 네모가 [데이터 추출], 노란 네모가 [백업 복구]입니다. (이미지를 누르면 크게 볼 수 있어요)*

> 기록이 하나도 없으면 **데이터 추출 메뉴 자체가 보이지 않습니다.** 이때는 [백업 복구]만 보이는 것이 정상입니다. 백업은 기록이 한 건이라도 있어야 할 수 있습니다.

![데이터 추출 후 브라우저에 뜬 다운로드 1개 완료 알림](/assets/images/ipotracker-backup/download-done.jpg){: .phone}

*데이터 추출을 하면 위쪽에 "다운로드 1개 완료" 알림이 뜹니다. [열기]를 누르면 받은 파일을 바로 열 수 있습니다.*

### 받은 파일은 어디에 있나요?

폰에서는 대부분 **다운로드 폴더**에 저장됩니다. 삼성폰이라면 **내 파일 → 다운로드**에서 찾을 수 있고, 브라우저 설정에 따라 위치가 다를 수 있으니 알림의 **[열기]** 로 한 번 확인해 두세요.

![폰의 다운로드 폴더에 저장된 공모주 백업 JSON, 수익 CSV 파일](/assets/images/ipotracker-backup/download-folder.jpg)

*다운로드 폴더 화면. 맨 위가 `공모주_백업_날짜.json`, 그 아래가 `공모주_수익_날짜.csv`입니다. 그 아래의 `infinity_buy_...json`은 무한매수 관리앱의 백업 파일입니다.*

사진을 보면 **두 도구의 백업 파일 이름이 서로 다릅니다.** 공모주 관리 도구는 `공모주_...`, [무한매수 관리앱]({{ site.baseurl }}{% post_url 2026-10-25-infinite-buying-backup-restore %})은 `infinity_buy_...json`입니다. 두 파일은 형식이 달라서 **서로의 도구에서는 불러올 수 없으니** 이름으로 구분해 보관하세요.

> 파일 이름의 날짜는 세계 표준시(UTC) 기준이라, 한국 시간으로 새벽 0시~9시 사이에 백업하면 **하루 전 날짜**가 붙을 수 있습니다. 위 사진도 10월 26일 오전 6시 47분에 받았는데 파일 이름에는 `2026-10-25`가 붙어 있습니다. 파일 내용에는 영향이 없습니다.

### 백업 파일은 이렇게 보관하세요

- 폰에만 두지 말고 **나에게 메일 보내기**, **클라우드(구글 드라이브, 원드라이브 등)**, **메신저의 나에게 보내기** 중 하나에 한 부 더 올려 둡니다. 폰을 잃어버리거나 초기화하거나, **폰 정리하면서 다운로드 폴더를 비우면** 폰 안의 파일도 같이 사라지기 때문입니다.
- 파일에는 **내 투자 기록**이 들어 있습니다. 다른 사람에게 공유하지 마세요.
- JSON 파일은 열어서 **직접 수정하지 마세요.** 형식이 깨지면 복구가 되지 않을 수 있습니다.

## 복구하는 방법

새 폰이나 다른 브라우저에서 도구를 열고, 백업 파일을 불러오는 순서입니다.

1. 새 기기의 브라우저에서 [공모주 관리 도구](https://mzmzkgu.github.io/ipotracker/)를 엽니다.
2. 오른쪽 위 **⚙️ 톱니바퀴 버튼**을 눌러 **설정** 창을 엽니다.
3. **백업 복구**(CSV 또는 JSON 파일에서 복구)를 누릅니다. (위 사진의 노란 네모)
4. **"백업에서 복구"** 창이 뜨면 파란 **[파일 선택 (CSV / JSON)]** 버튼을 누릅니다.
5. 폰의 파일 선택 창에서 백업해 둔 **`공모주_백업_날짜.json`** 파일을 고릅니다.
6. 도구에 기록이 하나도 없으면 바로 불러오고, 이미 기록이 있으면 아래 **병합/덮어쓰기** 질문이 먼저 나옵니다.
7. 마지막에 **"✅ N건 가져왔어요!"** 라는 알림이 뜨면 복구가 끝난 것입니다.

![공모주 관리 도구의 백업에서 복구 창과 파일 선택 버튼](/assets/images/ipotracker-backup/restore-sheet.jpg){: .phone}

*[백업 복구]를 누르면 나오는 창. 파란 [파일 선택] 버튼을 눌러 백업 파일을 고릅니다. 마음이 바뀌면 [취소]를 누르면 됩니다.*

백업 파일이 파일 선택 창에 안 보이면 **내장 저장공간 → Download(다운로드)** 폴더를 찾아보세요. 메일이나 클라우드에 올려 둔 파일은 먼저 새 기기로 내려받아야 선택 창에 나타납니다.

### 이미 기록이 있다면: 병합 or 덮어쓰기

도구에 이미 거래가 있는 상태에서 파일을 고르면 이런 확인 창이 뜹니다.

> 기존 N건 있어요.
> [확인] 병합 / [취소] 덮어쓰기

**버튼 이름과 기능이 헷갈리기 쉬우니 꼭 확인하세요.**

| 누른 버튼 | 결과 |
|---|---|
| **확인** | **병합**: 지금 있는 기록은 그대로 두고, 파일의 기록을 앞쪽에 **추가**합니다 |
| **취소** | **덮어쓰기**: 지금 있는 기록을 모두 지우고 **파일의 기록으로 통째로 바꿉니다** |

상황별로는 이렇게 고르면 됩니다.

| 상황 | 추천 |
|---|---|
| 새 폰에서 처음 복구 (기록이 비어 있음) | 질문이 뜨지 않고 바로 불러옵니다 |
| 기록이 일부만 남아 있어서 백업 파일 내용으로 **깔끔하게 되돌리고 싶음** | **취소(덮어쓰기)** |
| 새 폰에서 이미 몇 건 입력했고, 옛 기록을 **추가로** 가져오고 싶음 | **확인(병합)** |

- **병합은 같은 거래를 알아서 걸러 주지 않습니다.** 같은 파일을 병합으로 두 번 불러오거나, 이미 들어 있는 거래가 파일에도 있으면 **같은 거래가 중복**으로 들어갑니다. 중복이 생기면 거래목록에서 하나씩 삭제해야 합니다.
- **덮어쓰기는 되돌릴 수 없습니다.** 새로 입력한 기록이 있다면 덮어쓰기 전에 **지금 상태를 먼저 한 번 추출(백업)** 해 두세요.
- 기록이 많이 쌓인 기기에 옛 백업을 덮어쓰면 **최근 기록이 사라질 수 있으니**, 파일 날짜를 꼭 확인하세요.

### 복구가 안 될 때

**"❌"** 로 시작하는 경고창이 뜨면 파일에 문제가 있는 것입니다.

| 경고 문구 | 이런 뜻입니다 |
|---|---|
| ❌ 유효한 JSON이 아닙니다 | 공모주 도구에서 만든 JSON이 아니거나, 비어 있거나 손상된 파일입니다. 무한매수 관리앱의 `infinity_buy_...json` 파일을 고르면 이 경고가 뜹니다 |
| ❌ 유효한 CSV가 아닙니다 / 데이터 없음 | CSV에 표 제목이나 거래 줄이 없는 경우입니다 |
| ❌ 파일 읽기 실패 | 파일을 읽지 못한 경우입니다. 다시 내려받아서 시도해 보세요 |
| ❌ 뒤에 알아보기 어려운 영어 문구가 이어짐 | JSON 파일의 형식 자체가 깨진 경우입니다. 파일을 직접 수정했거나 일부만 내려받았을 때 생깁니다 |

파일 이름이 **`공모주_백업_...json`** 인지 먼저 확인하고, 다른 날짜의 백업 파일로도 시도해 보세요.

## 자주 묻는 질문

**자동으로 백업되나요?** 아니요. 도구가 서버를 쓰지 않아서 **직접 [데이터 추출]을 해야** 만들어집니다. 자동 동기화도 없습니다. 그래서 한 달에 한 번이나 청약 시즌이 끝날 때처럼 **나만의 주기**를 정해 두는 것을 권합니다.

**폰에서 만든 백업을 PC에서도 복구할 수 있나요?** 같은 도구의 JSON 파일이라서 기기가 달라도 복구할 수 있습니다. PC 브라우저에서 도구를 열고 같은 순서로 [백업 복구]를 누르면 됩니다.

**CSV 파일로 복구해도 되나요?** 됩니다. 다만 CSV는 엑셀에서 보기 편한 형식이라 입력값 외에 계산된 열도 들어 있습니다. 복구가 목적이라면 **JSON을 쓰는 것이 가장 안전**합니다.

**백업 파일은 몇 개나 모아 둘까요?** 파일이 작으니 날짜별로 여러 개 두어도 괜찮습니다. 가장 최근 파일 하나와, 청약 시즌이 끝났을 때 만든 파일 몇 개 정도를 남기면 충분합니다.

**무한매수 관리앱의 백업 파일을 여기서 불러올 수 있나요?** 불러올 수 없습니다. 두 도구의 파일 형식이 다릅니다. 각자의 도구에서 만든 파일은 각자의 도구에서만 복구하세요.

## 정리

공모주 관리 도구의 기록은 **내 브라우저에만** 있어서, **폰 정리나 기기 변경 때 사라질 수 있습니다.** **⚙️ 설정의 [데이터 추출]로 JSON 파일을 만들어 두는 것이 유일한 안전장치**입니다. 복구는 [백업 복구]에서 하고, 이미 기록이 있을 때는 **확인 = 병합, 취소 = 덮어쓰기**라는 점만 기억하세요. 그리고 백업 파일은 폰 밖(메일, 클라우드)에도 한 부 보관해 두세요.
